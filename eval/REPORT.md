# job-switch 품질 평가 리포트 (중간)

> 상태: 2026-10-16 기준 중간 리포트. 모델 비교(3단계)와 개선 전후 비교(4단계)는 아직 하지 않았습니다.

## 무엇을 쟀나

- 대상: `supabase/functions/job-switch` — JD 분석(Haiku) → 근거 매칭(Sonnet) → 문장 재작성(Sonnet) → 서버 검증(`verifyProject`, 숫자·영문 용어만 확인)
- 데이터: 직접 만든 **가상** 포트폴리오 12개 × 공고 2개 = **24 케이스**. 실존 인물 데이터 없음
- 실행: `base-iso` — 격리 모드(정답 요구사항을 2단계에 그대로 넣어 1단계 오류를 분리), 케이스당 1회, 재작성 문장 **606개**
- 판단 주체를 항상 구분합니다
  - **[자동]** 코드로 센 것
  - **[사람]** 사람이 정한 정답 또는 사람이 검수한 것
  - **[LLM 판정]** 다른 계열 모델(Gemini)이 판정한 것 — 사람 검수로 정확도를 따로 잼

### 재작성(3단계) 날조 — 사람 검수 79건

판정 모델 `gemini-3.6-flash`(2 케이스는 3.7 혼용). 사람은 LLM 판정을 보기 전에 결정했습니다(블라인드).
표본은 **LLM 이 날조라 한 39문장 전부 + LLM 이 정상이라 한 567문장 중 무작위 40문장**입니다.
재현: `npm run eval:agreement` (데이터 `eval/review/judge-human.json`)

| | 사람 날조 | 사람 정상 |
|---|---|---|
| LLM 날조 | 27 | 12 |
| LLM 정상 | 4 | 36 |

| 지표 | 값 |
|---|---|
| 사람–LLM 일치 | 63/79 (79.7%) |
| LLM 판정 정밀도 | 27/39 = 69.2% (95% 53.6~81.4%) |
| LLM 이 놓친 비율 | 4/40 = 10.0% (95% 4.0~23.1%) |
| **보정한 전체 날조율** | **13.8% ≈ 84/606문장** (보수적 구간 7.2~26.8%) |
| **서버 검증기가 잡은 비율** | **사람이 날조로 본 31건 중 3건** |

- 검수 표본의 날조 비율(31/79)은 층화 표본이라 **전체 날조율이 아닙니다.** 전체는 층별 비율로 다시 가중한 13.8% 입니다.
- 서버가 잡은 3건 중 2건은 숫자·영문 용어가 든 문장(LCP 기준 충족, B2B SaaS)이었습니다. 서버 경고 중 사람이 정상으로 본 것은 1건 있었습니다.
- LLM 판정만 쓰면 날조율을 6.4%(39/606)로 보게 되는데, 사람 검수로 보정하면 약 2배입니다. LLM 판정은 과하게 잡는 쪽(오탐 12)과 놓치는 쪽(4/40)이 동시에 있습니다.

### 놓친 날조 유형 [사람 코멘트 기준]

모두 한글 주장이라 숫자·영문 용어만 보는 서버 검증기 구조로는 잡을 수 없습니다.

| 유형 | 원문 → 재작성 |
|---|---|
| 방법 격상 | 동료에게 써 보게 하고 의견 받음 → "사용성 테스트를 직접 설계·진행" · 시안 A·B 공유 → "실험" · 두 소재 번갈아 집행 → "A/B 테스트" |
| 하지 않은 행동 추가 | 이미지 12종 제작 → "유관 부서와 요구사항 조율" · 결과 공유 → "우선순위 조정 합의를 이끔" |
| 없는 성과 덧붙임 | 세 단계로 묶음 → "단계별 전환율을 추적할 수 있게" · 화면 재설계 → "과제 성공률을 높여" |
| 도메인·용어 바꿔치기 | 유료 전환 → "구독 전환" · 수업 판매 → "B2B SaaS" · 디자인 담당 → "기획과 디자인" |

판정 기준은 `eval/cases/AUTHORING.md` '판정 기준' — 매칭은 partial 을 인정하고, 재작성에서 partial 의 빠진 핵심을 공고 단어로 채우면 날조입니다.
사람 검수에서 LLM 이 날조라 한 12건을 정상으로 판정한 것은, 원문 사실 안에서 직무 언어로 옮긴 정도의 포장은 허용했기 때문입니다.

### 원인 가설 [자동 + LLM 판정]

재작성 프롬프트(`rewritePrompt`)가 매칭 결과의 full/partial 을 구분하지 않고 같은 "근거"로 넘깁니다.

| 문장이 대응하는 요구사항 | LLM 판정 날조율 | 금지어 포함률 |
|---|---|---|
| partial | 19.1% (9/47) | 17.0% (8/47) |
| full | 4.9% (12/243) | 2.1% (5/243) |

LLM 판정 기준 수치라 사람 보정 전입니다. 개선 실험(4단계)의 대상입니다.
