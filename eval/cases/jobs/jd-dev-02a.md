# [가상 공고] 페이지원 — 프론트엔드 엔지니어 (구독 웹)

> 평가용 가상 공고입니다. 실존 회사·채용과 무관합니다.

## 팀 소개
페이지원은 전자책과 오디오북을 월 구독으로 제공하는 서비스입니다. 웹 팀은 도서 탐색, 상세, 구독 결제까지 사용자가 웹에서 만나는 모든 화면을 만듭니다. 방문자의 대부분이 모바일 브라우저로 들어오기 때문에 첫 화면 속도와 결제 흐름을 특히 신경 씁니다.

## 주요 업무
- React·Next.js 기반 웹 서비스 개발과 운영
- 도서 상세·탐색 페이지 성능 개선
- 구독 결제 흐름의 화면 구현과 개선
- 디자이너와 함께 공통 컴포넌트 설계와 관리

## 자격 요건
- React와 TypeScript를 사용한 웹 개발 경험
- 프론트엔드 개발 경력 2년 이상
- Core Web Vitals 등 웹 성능 지표를 측정하고 개선한 경험
- Next.js 등을 이용한 서버 사이드 렌더링 경험
- 여러 화면에 걸친 클라이언트 상태를 설계하고 관리해 본 경험
- 단위 테스트 작성 경험

## 우대 사항
- 디자이너와 협업해 공통 컴포넌트나 디자인 시스템을 만든 경험
- 웹 접근성을 고려한 마크업 경험
- 결제·가입 등 전환 흐름을 개선해 본 경험
- Sentry 등 프론트엔드 에러 모니터링 도구 운영 경험
