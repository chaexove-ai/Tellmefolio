# [가상 공고] 스테이로그 — 백엔드 엔지니어 (예약·결제)

> 평가용 가상 공고입니다. 실존 회사·채용과 무관합니다.

## 팀 소개
스테이로그는 국내 소형 숙소의 예약과 결제를 돕는 플랫폼입니다. 예약·결제 팀은 사용자가 결제 버튼을 누른 순간부터 확정 안내를 받기까지의 흐름 전체를 책임집니다.

## 주요 업무
- 예약·결제·정산 백엔드 API 설계와 개발
- 메시지 큐 기반 비동기 처리 구조 개선
- 트래픽이 몰리는 시즌의 안정성 확보와 장애 대응
- 운영팀과 협업해 정산·환불 규칙을 코드로 옮기기

## 자격 요건
- Node.js 또는 Python 기반 백엔드 개발 경험 3년 이상
- PostgreSQL 등 관계형 데이터베이스 설계와 쿼리 튜닝 경험
- 메시지 큐(SQS, Kafka 등)를 활용한 비동기 처리 경험
- 중복 처리·재시도 등 분산 환경의 정합성 문제를 다뤄 본 경험
- 테스트 코드 작성과 CI 기반 배포 경험

## 우대 사항
- 결제·정산 도메인 경험
- 장애 상황을 가정한 설계(재시도 상한, 실패 큐 등) 경험
- 비개발 부서와 규칙을 정리하고 합의해 본 경험
- 응답 시간 등 성능 지표를 측정하고 개선한 경험
- Terraform 등 IaC 도구 사용 경험
