# [가상 공고] 장바구니마켓 — 백엔드 엔지니어 (주문 플랫폼)

> 평가용 가상 공고입니다. 실존 회사·채용과 무관합니다.

## 팀 소개
장바구니마켓은 동네 마트 상품을 당일 배송하는 장보기 커머스입니다. 주문 플랫폼 팀은 주문 생성부터 결제 승인, 배송 요청, 정산 데이터 생성까지 이어지는 백엔드 시스템을 맡고 있습니다. 저녁 시간대에 주문이 짧게 몰리는 특성이 있어 안정성을 가장 중요하게 봅니다.

## 주요 업무
- 주문·결제 백엔드 API 설계와 개발
- 이벤트 기반 비동기 처리 구조 운영과 개선
- 부하 테스트로 병목을 찾고 처리량 개선
- 장애 대응과 모니터링 체계 정비
- 백엔드 파트 리딩 및 주니어 엔지니어 코드 리뷰

## 자격 요건
- Java, Kotlin 또는 Node.js 기반 백엔드 개발 경험
- 일 주문 10만 건 이상 규모의 대용량 트래픽 처리 경험
- 메시지 큐를 활용한 비동기 처리 경험
- 재시도·중복 방지 등 데이터 정합성을 보장해 본 경험
- 테스트 자동화와 CI/CD 파이프라인 운영 경험
- 부하 테스트(nGrinder, k6 등)로 성능 병목을 찾고 개선한 경험

## 우대 사항
- 결제·정산 도메인 경험
- 운영 중 장애 대응과 모니터링 체계 구축 경험
- 백엔드 파트를 리딩하거나 주니어를 멘토링한 경험
- 운영·CS 등 비개발 부서와 협업해 업무 규칙을 시스템에 반영한 경험
