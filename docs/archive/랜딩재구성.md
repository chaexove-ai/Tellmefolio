# 랜딩 재구성 (v3) — v2 위에 얹는 패치

v2를 이미 적용하신 상태에서 이 파일들을 덮어쓰면 됩니다.

```
src/landingContent.ts              ← 신규 (랜딩 문구를 한곳에 모음)
src/components/BeforeAfterDemo.tsx ← 신규
src/components/Faq.tsx             ← 신규
src/pages/Landing.tsx              ← 덮어쓰기
src/index.css                      ← 덮어쓰기 (summary 마커 숨김 규칙만 추가)
```

```bash
npm run build && npm run dev
```

## 바뀐 정보 구조

```
  기존                          변경
  ─────────────────────         ─────────────────────
  히어로                        히어로 (보조 CTA 제거)
  지구본                        히어로 모션 (교체 예정)
  핵심 기능 3카드         →     같은 경험, 다른 직무 언어   ← 신설
  이런 분께 맞습니다            어떻게 만들어지나요         ← 신설
  최종 CTA                      갤러리 미리보기
                                이런 분께 맞습니다
                                자주 묻는 질문             ← 신설
                                최종 CTA + 푸터
```

**"핵심 기능" 3카드는 삭제했습니다.** 세 카드가 하던 이야기를 Before-After 데모와
3단계 섹션이 더 구체적으로 대신합니다. 기존 랜딩은 같은 말을 세 번 반복하고 있었습니다.

### 1. 같은 경험, 다른 직무 언어 (신설)

원본 메모 한 줄을 보여주고, 직무 탭(프론트엔드 / UX / 기획)을 누르면
같은 프로젝트가 그 직무의 언어로 다시 쓰인 결과가 나옵니다.

이 서비스의 유일한 차별점인데 기존에는 카드 한 장의 본문에 묻혀 있었습니다.
글로 설명할 게 아니라 나란히 보여줘야 이해되는 종류입니다.

- 탭 위젯 표준(`role=tablist/tab/tabpanel`) 준수, 좌우 방향키 이동 지원
- ⚠️ **내용은 기능 설명용 가상 예시입니다.** 화면에도 "예시"라고 표기됩니다.
  실제 사례로 교체하실 때는 당사자 동의를 받고 표기도 함께 바꿔주세요.

### 2. 어떻게 만들어지나요 (신설)

`/wizard` 에 이미 잘 정리된 1-2-3 단계가 있는데, 로그인 전 방문자는 볼 수 없었습니다.
랜딩에 "어떻게 동작하는지"가 아예 없다는 게 큰 구멍이었습니다.

### 3. 자주 묻는 질문 (신설)

`<details>/<summary>` 를 그대로 써서 키보드·스크린리더 동작을 브라우저에 맡겼습니다.

> ⚠️ **`src/landingContent.ts` 의 FAQ 답변 중 2개는 `TODO` 로 비워뒀습니다.**
> - "제 자료가 AI 학습에 사용되나요?"
> - "무료인가요?"
>
> 제가 임의로 채울 수 없는 내용입니다. 특히 데이터 정책은 잘못 쓰면
> 신뢰 문제가 아니라 법적 문제가 됩니다. **실제 방침으로 반드시 교체 후 배포하세요.**

### 4. 히어로 보조 CTA 제거

"결과물 먼저 보기" 버튼을 뺐습니다. 아래에 갤러리 섹션이 있고 헤더에도 링크가 있어
중복이었고, CTA 두 개가 나란히 있으면 주 버튼의 무게만 깎였습니다.

## 문구 수정 방법

`src/landingContent.ts` 한 파일만 열면 됩니다.
Before-After 예시, 3단계 설명, FAQ 문답이 전부 거기 있습니다.
컴포넌트는 건드릴 필요 없습니다.

`Landing.tsx` 의 h1 위에 **대안 카피**를 주석으로 적어뒀습니다.
현재 h1("AI 포트폴리오 제작 도구")은 카테고리 설명에 가깝고,
대안("하나의 경험을, 지원하는 직무마다 다시 씁니다")은 이 서비스만의 문장입니다.
바꾸실 거면 `index.html` 의 `og:title` / `twitter:title` 도 함께 맞춰주세요.
