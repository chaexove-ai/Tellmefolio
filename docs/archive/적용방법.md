## 먼저: 정정 2건

### ① "첫 화면이 빈 페이지로 뜬다" — 제 측정 오류였습니다

리포트에서 이걸 P0 1순위로 올렸는데, **재현 환경의 문제였습니다.**

자동화 브라우저 탭이 `visibilityState: "hidden"` 상태였고, 그래서
`requestAnimationFrame`이 한 번도 실행되지 않았습니다. 실측:

```
{ t:    0ms, opacity: "0", rafCount: 0, visibilityState: "hidden" }
{ t: 1470ms, opacity: "0", rafCount: 0, visibilityState: "hidden" }
{ t: 4469ms, opacity: "0", rafCount: 0, visibilityState: "hidden" }
```

GSAP은 rAF로 구동되므로, rAF가 멈춘 탭에서는 타임라인이 시작 상태
(`opacity: 0`)에 그대로 멈춰 있습니다. **실제 사용자가 보통 탭에서 열면
정상적으로 재생됩니다.** 잘못된 정보를 드렸습니다.

다만 남는 것이 두 가지 있어서 그 부분만 손봤습니다.

- **백그라운드 탭으로 열릴 때** (cmd+클릭, 세션 복원, 링크 미리 열어두기)
  탭을 활성화하기 전까지는 빈 화면입니다. 자동 복구되지만 안전장치를 넣었습니다.
  → `Landing.tsx`: 2.5초 안에 타임라인이 끝나지 않으면 애니메이션을 포기하고 표시.
- **`Reveal.tsx` 의 인라인 `style={{ opacity: 0 }}`** — 이건 진짜 위험합니다.
  GSAP 번들 로드가 실패하면 핵심 기능·대상 고객 섹션이 **영구히** 안 보입니다.
  히어로는 `useEffect` 안에서 `gsap.set` 으로 숨기므로 JS가 죽으면 오히려
  그냥 보이는데, Reveal은 마크업에 박혀 있어서 복구 경로가 없습니다.
  → 인라인 값을 제거했습니다.

### ② "다크 모드에서 html class가 비어 있다" — 버그가 아니었습니다

`index.css`가 `:root.light` 만 키로 쓰고 `ThemeContext.tsx` 도 `.light` 만
토글합니다. 다크가 기본값이므로 클래스가 없는 것이 정상입니다. 설계대로입니다.
v1에서 `dark` 클래스를 추가했던 것을 **되돌렸습니다.**
`<body class="bg-neutral-950 text-neutral-100">` 도 원상 복구했습니다
(`bg-neutral-950` 은 CSS 변수 기반이라 라이트에서 `#faf7f1` 로 바뀝니다 —
제가 v1에서 잘못 지웠습니다).

### 그대로 유효한 것

폰트 2.18MB, SEO 메타 전무, 대비율 미달, `<main>`/`<footer>` 부재,
헤더 non-sticky, 캔버스 4배 오버드로, 갤러리 미노출, soft 404 — **전부 재확인했습니다.**

## 적용

프로젝트 루트에 그대로 덮어쓰면 됩니다.

```
index.html                      ← 덮어쓰기
vercel.json                     ← 덮어쓰기
tailwind.config.js              ← 덮어쓰기
src/index.css                   ← 덮어쓰기
src/pages/Landing.tsx           ← 덮어쓰기
src/components/Reveal.tsx       ← 덮어쓰기
src/components/HeroGlobe.tsx    ← 덮어쓰기
public/robots.txt               ← 신규
public/sitemap.xml              ← 신규
public/manifest.webmanifest     ← 신규
public/og.png                   ← 신규
```

```bash
npm run build
vercel --prod
```

> `npm run build` 가 `tsc -b && vite build` 라 타입 에러가 있으면 여기서 멈춥니다.
> 에러 메시지 그대로 붙여주시면 바로 고쳐드리겠습니다.

## 수정 내용

### 폰트 2.18MB → 대폭 감소 (`index.html`)

```diff
- pretendard@v1.3.9/dist/web/variable/pretendardvariable.css
+ pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.css
```

계측값: `.woff2` 11개 / 2,181KB, `@font-face` 191개 (Gowun Batang 190 + Pretendard 1).
Pretendard 풀셋 1개 파일이 대부분을 차지했습니다. `cdn.jsdelivr.net` preconnect 추가.

### SEO / 공유 (`index.html`, `public/*`, `vercel.json`)

description, canonical, theme-color, Open Graph 전체, Twitter Card,
JSON-LD, robots.txt(네이버 Yeti·다음 명시), sitemap.xml, manifest.
`vercel.json` rewrite에 정적 파일 예외를 넣어 이들이 index.html로 삼켜지지 않게 했습니다.
캐시·보안 헤더도 함께 넣었습니다.

OG 이미지(`public/og.png`, 1200×630)는 브랜드 톤에 맞춰 새로 만들어 넣었습니다.

### 대비율 — 액센트 색을 테마별로 분리 (`tailwind.config.js`, `src/index.css`)

기존 `brand: "#c2703d"` 단일 값으로는 **양쪽 테마를 동시에 만족할 수 없습니다.**

| 용도 | 기존 | 기준 |
|---|---|---|
| 라이트 배경 위 `text-brand` | 3.50:1 | 4.5:1 미달 |
| 다크 배경 위 `text-brand` | 5.36:1 | 통과 |
| `bg-brand` + 흰 글자 버튼 | 3.70:1 | 미달 |

라이트를 통과시키려면 어둡게 해야 하는데 그러면 다크가 떨어집니다.
그래서 neutral과 같은 방식으로 액센트도 CSS 변수로 분리했습니다.

```
--brand        다크 194 112 61 (5.36:1) / 라이트 160 88 41 (5.06:1)
--brand-solid  양쪽 공통 168 92 48  → 흰 글자 4.95:1  (.btn-primary 배경)
--brand-dark   hover 상태
```

추가로 다크 테마 `--n500` 을 115 → 125 로 올렸습니다.
(다크 배경 위 4.18:1 → 4.81:1. "핵심 기능" 등 섹션 제목이 이 값을 씁니다)

히어로 힌트 문구는 `text-neutral-600`(2.52:1) → `text-neutral-500` 로 바꿨습니다.

전역 `:focus-visible` 포커스 링과 `prefers-reduced-motion` 안전장치도 추가했습니다.

### sticky 헤더 + 갤러리 미리보기 (`src/pages/Landing.tsx`)

- 헤더를 `sticky top-0` + backdrop-blur 로 변경. 기존에는 스크롤 시작 즉시
  CTA가 사라져 2000px 구간 내내 누를 버튼이 없었습니다.
- `<main>`, `<footer>`, 본문 바로가기 링크 추가 (스크린리더 랜드마크)
- **갤러리 미리보기 섹션 신설** — `mockData.ts` 의 `galleryItems` 앞 3개를
  "이렇게 만들어집니다" 섹션으로 노출하고 `/gallery` 로 연결했습니다.
  결과물 이미지가 0개였던 것이 이 랜딩의 가장 큰 전환 손실이었습니다.
- 히어로에 "결과물 먼저 보기" 보조 CTA 추가
  (→ **`/wizard`, `/gallery` 가 로그인 없이 열리는 게 의도인지 확인 필요.**
  가드를 거실 거면 이 버튼을 지워주세요)
- 히어로 애니메이션 안전장치 (위 정정 ① 참고)

### 캔버스 최적화 (`src/components/HeroGlobe.tsx`)

- `width * 2` + `devicePixelRatio: 2` → 380px 표시에 1520px 버퍼(4배)였습니다.
  실제 DPR 기준으로 맞춰 **픽셀 수를 1/4로** 줄였습니다.
- 화면 밖으로 나가면 rAF 루프를 멈춥니다 (IntersectionObserver).
  랜딩이 2000px가 넘는데 글로브는 첫 화면에만 있습니다.
- `prefers-reduced-motion` 에서 자동 회전 중지 (드래그는 유지)
- 캔버스에 `role="img"` + 대체 텍스트
